# InterviewAI
HTML + CSS + vanilla JavaScript. Chart.js via CDN. LocalStorage is the demo database. Demo AI Mode works with no API key.
## Run
`python -m http.server 5500` then open http://localhost:5500 (or use VS Code Live Server).
## Demo accounts (demonstration only)
Student: student@interviewai.demo / student123
Faculty: faculty@interviewai.demo / faculty123
Admin: admin@interviewai.demo / admin123
## Features
Landing page, register/login/roles, dashboard, diagnostic, practice, timed mock tests, coding (JS runs in browser, other languages simulated), AI interview, AI chatbot, analytics, recommendations, achievements, printable report, profile, settings, dark/light theme, faculty (students, question CRUD) and admin (users, questions).
## Security
This is a frontend demonstration. Production deployment should use a secure backend with hashed passwords, server-side authentication, authorization and protected API keys.
